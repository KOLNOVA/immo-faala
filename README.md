# Immo-Faala

Plateforme immobilière numérique en Afrique de l'Ouest.

## Stack Technique
- **Frontend** : Next.js 16 + React + TypeScript
- **Backend** : API Routes Next.js + Supabase
- **Base de données** : Supabase (PostgreSQL)
- **Authentification** : NextAuth.js + bcrypt
- **Hébergement** : Vercel

## Fonctionnalités
- ✅ Inscription / Connexion / Déconnexion
- ✅ Dashboard annonceur
